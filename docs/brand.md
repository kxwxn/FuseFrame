# FuseFrame Brand Direction

## Positioning

FuseFrame is the AI-ready frame for shipping SaaS faster.

The product is a cloneable starter repo for founders using AI coding agents. It provides tested blocks for auth, payments, webhooks, dashboards, and revenue attribution so the agent can build product features instead of rebuilding SaaS plumbing.

## Core Message

Fuse in the frame. Ship the product.

## Voice

- Direct, technical, and founder-focused.
- Sell saved build time and fewer broken SaaS primitives, not abstract AI magic.
- Prefer short verbs: fuse, wire, ship, verify, extend.
- Avoid claiming hosted analytics, marketplace features, or Korea-specific payment support in v1.

## Visual System

- Base: white, ink black, steel borders, compact mono details.
- Accents: electric blue for links and primary product paths, volt green for AI instruction and fuse points, ember orange for event wiring and motion.
- Shapes: square frames, small radii, grid canvases, direct connector lines.
- Product imagery: show blocks being fused into one working SaaS frame.

## Taglines

- The AI-ready frame for shipping SaaS faster.
- Fuse in auth, billing, webhooks, dashboards, and attribution.
- Stop rebuilding the frame. Start shipping the product.

## Buyer

Solo founders and indie builders using Cursor, Codex, or Claude Code to launch a revenue-ready SaaS.
